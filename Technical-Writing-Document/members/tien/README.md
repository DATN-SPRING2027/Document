# Thư mục cá nhân — Tiên

## Hướng dẫn sử dụng
Đặt các file bản nháp cá nhân của bạn vào đây trước khi merge vào file chính thức:
- File .md bản nháp nội dung Use Case, thiết kế, test case...
- Ảnh chụp màn hình (.png, .jpg) để chèn vào báo cáo
- File ghi chú nghiên cứu, phác thảo sơ đồ

## Khi nhận task bất kỳ
1. Xem bảng tra cứu tại [QUY_DINH_LUU_Y_KHI_LAM_REPORT.md](../../QUY_DINH_LUU_Y_KHI_LAM_REPORT.md) để biết task thuộc loại nào và cần viết vào file nào.
2. Viết nháp ở đây, khi xong chuyển nội dung sang đúng file chính thức trong Submit-Report/ hoặc Output-DrawIo/.
3. Ghi một dòng vào [DOCUMENT_CONTRIBUTION_LOG.md](../../DOCUMENT_CONTRIBUTION_LOG.md).
