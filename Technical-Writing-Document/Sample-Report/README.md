# Sample-Report — Hướng dẫn tải file mẫu

Thư mục này chứa **các file báo cáo mẫu của trường và Checklist chấm điểm**. Vì file Word/Excel nặng (tổng ~80MB), chúng **không được push lên GitHub** mà mỗi thành viên tự tải về máy.

---

## Cách làm

### 1. Tải file mẫu
Tải toàn bộ thư mục `Sample-Report` từ link Google Drive do nhóm chia sẻ (hỏi Phúc lấy link).

### 2. Bỏ vào đúng thư mục này
Sau khi tải xong, giải nén và đặt các file vào đúng thư mục:
```
Document/Technical-Writing-Document/Sample-Report/
```
