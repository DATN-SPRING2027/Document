Nhóm **không phân module cố định** cho từng người. Ai nhận task nào thì:
1. Tra bảng [QUY_DINH](QUY_DINH_LUU_Y_KHI_LAM_REPORT.md) để biết task thuộc loại nào → viết vào file nào.
2. Viết nháp trong folder cá nhân `members/<tên>/`.
3. Chuyển sang file chính thức, mở PR, ghi nhật ký.
